# 🎨 Storytold - The Crafting Apps

Lista completa de aplicativos ArtCraft/Storytold para referência rápida e desenvolvimento.

## 📸 Edição de Imagem e Design

| App | Descrição | Link |
|---|---|---|
| **PhotoCraft** | Editor de imagens com camadas e suporte a PSD (Alternativa ao Photoshop) | [github.com/storytold/photocraft](https://github.com/storytold/photocraft) |
| **LightCraft** | Biblioteca de fotos e revelação de arquivos RAW não-destrutiva | [github.com/storytold/lightcraft](https://github.com/storytold/lightcraft) |
| **VectorCraft** | Ilustração vetorial com caneta, formas e gradientes | [github.com/storytold/vectorcraft](https://github.com/storytold/vectorcraft) |
| **DesignCraft** | Editor de layout de página e publicação (Alternativa ao InDesign) | [github.com/storytold/designcraft](https://github.com/storytold/designcraft) |
| **FigCraft** | Design de interface (UI/UX) e prototipagem colaborativa | [github.com/storytold/figcraft](https://github.com/storytold/figcraft) |
| **TextureCraft** | Fluxo de trabalho para pintura de texturas 3D | [github.com/storytold/texturecraft](https://github.com/storytold/texturecraft) |
| **MaterialCraft** | Designer de materiais visuais baseado em nós (node-based) | [github.com/storytold/materialcraft](https://github.com/storytold/materialcraft) |
